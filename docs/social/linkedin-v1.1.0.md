## Post

A homebrew game is a love letter to a machine that stopped being sold years ago.

Someone still writes new games for the Game Boy. Someone still publishes cartridges for the NES. Finding them is the hard part. The links live across forums, wikis, itch.io tags and jams.

So we built Awesome Homebrew Games.

It is a curated directory of 69 places across 21 platforms, with a landing page that boots like a handheld. Insert the cartridge, pick your machine, and the shelf shows only the places that serve it.

What shipped in v1.1.0:

→ A narrative landing page: the cartridge's route, from the desk to passing it on
→ Animated SVG illustrations in the README, with reduced-motion fallbacks
→ Proper SEO: canonical, structured data, robots.txt and a generated sitemap
→ A daily discovery workflow that scans the web and the GitHub API for new platforms, games, boards and forums
→ A review skill that triages candidates, checks duplicates and audits the whole list

Automation finds candidates. People decide what gets in. Every entry is reviewed before it reaches the directory.
